# 自动选集下载（长视频平台 · 学习参考版）

把用户的自然语言指令翻译成对脚本 `src/main.py` 的命令行调用。
本目录自带：`SKILL.md`（本说明书）+ `src/main.py`（主程序）+ `src/ts_merge.py`（下载/合并依赖，必须和主程序放同目录，缺它无法下载）。
脚本能力：搜索关键词 → 自动选中正片入口（预约/预告/花絮卡自动跳过）→ 抓全部季与集 → 逐集下载 ts 分片合并成 mp4，断点续传、每集随机延时防风控。

> 注意：这是脱敏后的学习参考代码。代码里的站点选择器、URL 占位都已抽象（card-title / sub-title / ep-item-row / ep-cell / `#ep-list` / `#search-input`/'**'），
> 请先把 `src/main.py` 顶部的 `HOME` 和选择器适配成你的目标站点后再跑，否则会找不到元素。

## 指令 → 参数映射
| 用户指令示例 | 命令行参数 |
|---|---|
| 下载某剧全部内容 / 全部季与集 / 正片全部内容 | `--kw 某剧 --mode all` |
| 下载《xxx》最新的一集 | `--kw xxx --mode latest` |
| 下载《xxx》第3集 | `--kw xxx --mode ep --ep 3` |
| 更新《xxx》（只补最新更新的集） | `--kw xxx --mode update` |

## 执行步骤
1. 从用户指令提取节目名：优先取书名号《》/引号内的词；没有则去掉"下载/长视频/全部内容/全部季与集/最新的一集/第N集/更新"等词后的主体（保留"某剧第二季"这类带季的完整剧名）。
2. 让用户在编辑器终端或命令行手动运行（脚本窗口化、可 Ctrl+C 中断，中断后已存盘/断点；在 `src/` 目录下执行）：
   ```
   python main.py --kw "节目名" --mode all
   ```
   （latest/ep/update 按映射表换参数）
3. 跟踪输出确认流程：搜索列表 → 进播放页收集集数（按季分组打印）→ 逐集"✅抓取 m3u8"→"下载→合并→完成 xx.mp4"。
4. 全部跑完后检查脚本所在目录（mp4 成品、`m3u8结果_{节目名}.json` 断点、`m3u8链接_{节目名}.txt` 都生成在脚本旁边）。

## 执行边界（铁律）
- 脚本没有任何自动/定时/后台/无头启动机制：只有**用户手动运行**才执行；断点续传（`m3u8结果_{节目名}.json`）也只发生在**下次手动运行时**。
- 用户关闭编辑器/终端、中断会话或任务 → **立即默认结束**：不后台继续、不自动重跑、不开无头补抓。
- **打开编辑器 / 双击 .py / 打开 IDE，不会触发任何运行**——脚本自身没有任何启动机制，只有被"显式调用"才运行。
- 下次用户手动给出指令时，用 `--mode update` 从断点补上未完成的集，已完成的集自动跳过。

## 注意事项
- 单实例锁：脚本在脚本目录生成 `.lock` 文件做防双开——若提示"检测到上一个实例仍在运行"，说明旧进程没停干净，先在任务管理器结束对应 python 进程再运行；脚本不会两个一起跑抢页面/断点文件。
- 别双击运行任何爬虫脚本（Windows 会把双击的 .py 直接拉起来跑）；想跑就在终端运行并盯着它结束。
- 成品命名：`{节目名}_{季}第N集_标题.mp4`；断点文件 `m3u8结果_{节目名}.json`、链接文件 `m3u8链接_{节目名}.txt`（每部剧独立）。
- m3u8 链接带签名有时效（几小时）：当天尽快跑完；报"链接失效"时删对应 `m3u8结果_{节目名}.json` 重新抓取。
- 预约/预告/花絮卡会自动跳过；未播出剧目不在下载列表内，属正常。
- 若输出"没有可进入的节目"，让用户换更完整的关键词（如"某某剧第二季"）再跑。
- 多季剧（如某剧第一、二季）会在一个播放页里通过季标签全部抓到，后面的同名季卡会自动跳过不重复下载。
